동사 10대 활용 공식 요약

1. 수동형 (受身) · ~에게 당하다

• 1그룹: 어미 う단 → あ단 + れる (書く → 書かれる / 飲む → 飲まれる)

• 2그룹: 어미 る 탈락 + られる (食べる → 食べられる)

• 3그룹: する → される / 来る → こられる(来られる)

2. 사역형 (使役) · ~하게 시키다

• 1그룹: 어미 う단 → あ단 + せる (書く → 書かせる / 飲む → 飲ませる)

• 2그룹: 어미 る 탈락 + させる (食べる → 食べさせる)

• 3그룹: する → させる / 来る → こさせる(来させる)

3. 사역수동형 (使役受身) · 억지로 시킴당하다

• 1그룹 축약형: 어미 う단 → あ단 + される (飲む → 飲まされる / 待つ → 待たされる)
*(단, す로 끝나는 1그룹은 話させられる 처럼 풀형태 사용)*

• 2그룹: 어미 る 탈락 + させられる (食べる → 食べさせられる)

• 3그룹: する → させられる / 来る → こさせられる

4. 가능형 (可能) · ~할 수 있다

• 1그룹: 어미 う단 → え단 + る (書く → 書ける / 飲む → 飲める)

• 2그룹: 어미 る 탈락 + られる (食べる → 食べられる)

• 3그룹: する → できる / 来る → こられる(来られる)
