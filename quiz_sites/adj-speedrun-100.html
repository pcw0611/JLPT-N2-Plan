형용사 8대 활용 공식 요약

1. い형용사 기본 8대 변형

• 부정형: 어미 い 탈락 + くない (高い → 高くない)

• 과거형: 어미 い 탈락 + かった (高い → 高かった)

• 과거부정: 어미 い 탈락 + くなかった (高い → 高くなかった)

• 부사형 (동사 수식): 어미 い 탈락 + く (高い → 高くする)

• 연결형 (て형): 어미 い 탈락 + くて (高い → 高くて)

• 가정형 (ば형): 어미 い 탈락 + ければ (高い → 高ければ)

• 명사화: 어미 い 탈락 + さ (高い → 高さ)

• 양태추측 (~해 보인다): 어미 い 탈락 + そうだ (高い → 高そうだ)

2. な형용사 (형용동사) 기본 8대 변형

• 명사 수식 (연체형): 어간 + な (静かだ → 静かな)

• 부사화 (동사 수식): 어간 + に (静かだ → 静かに)

• 연결형 (て형): 어간 + で (静かだ → 静かで)

• 부정형: 어간 + ではない / じゃない (静かだ → 静かではない)

• 과거형: 어간 + だった (静かだ → 静かだった)

• 과거부정: 어간 + ではなかった (静かだ → 静かではなかった)

• 가정형: 어간 + なら (静かだ → 静かなら)

• 양태추측 (~해 보인다): 어간 + そうだ (静かだ → 静かそうだ)

★ N2 필수 킬러: いい / よい 불규칙 활용

• 기본형만 いい, 모든 활용은 よい 기준!

• 부정: よくない (X いくない) / 과거: よかった (X いかった)

• 부사: よく / 연결: よくて / 가정: よければ

• 양태 (~좋아보인다): よさそうだ (X いいそうだ/よいそうだ)

• 명사화: よさ (X いいさ) / 복합: かっこよくない

★ N2 함정: い로 끝나지만 な형용사인 단어

• 綺麗だ (きれいだ) → 綺麗な (X きれいくない), 綺麗に, 綺麗ではない

• 嫌いだ (きらいだ) → 嫌いな (X きらいくない), 嫌いで, 嫌いではない

• 得意だ (とくいだ) → 得意な (X とくいくない), 得意に

• 丁寧だ (ていねいだ) → 丁寧な, 丁寧に入, 丁寧ではない

• 曖昧だ (あいまいだ) → 曖昧な, 曖昧に, 曖昧ではない

• 有名だ (ゆうめいだ) → 有名な (X ゆうめいくない)
