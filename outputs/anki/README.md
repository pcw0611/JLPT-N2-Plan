# JLPT N2 문법 001~025 Anki 가져오기

## 가장 간단한 방법

1. Anki에서 `파일 → 가져오기`를 연다.
2. `jlpt-n2-grammar-001-025-anki-import.txt`를 선택한다.
3. 노트 유형은 `기본(Basic)`을 선택한다.
4. 미리보기에서 `Front → 앞면`, `Back → 뒷면`, `Tags → 태그`인지 확인한다.
5. HTML 허용이 켜져 있는지 확인하고 가져온다.

파일 헤더에 탭 구분자, HTML 사용, 덱 이름, 태그 열이 지정되어 있다. 가져오면
`JLPT N2::문법 001-025 예문 복습` 덱에 25장이 생성된다.

`jlpt-n2-grammar-001-025-examples.tsv`는 전체 필드를 편집하거나 별도의 사용자
노트 유형에 매핑할 때 사용하는 원본이다.

## 카드 구성

- 앞면: 번호, 문형, 회상 지시
- 뒷면: 짧은 한국어 뜻, 접속, 핵심 의미, 일본어 예문 2개와 한국어 번역, 구별 포인트, 시험 신호
- 우선 태그: 최근 혼동 범위는 `priority_high`, 나머지는 `priority_normal`

기존 만기 복습이 44건 남아 있으므로 새 카드 25장을 한꺼번에 모두 학습하기보다
`priority_high`부터 5~8장씩 여는 것을 권장한다.
