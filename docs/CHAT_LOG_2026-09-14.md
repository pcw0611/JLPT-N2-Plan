02 조사 핵심
==================================================

단순히

に = 에
で = 에서

식으로 외우게 하지 말 것.

실제 문장의 기능과 차이를 판단하도록 만든다.

は / が
に / で
を / が
に / へ

9時まで働く。

포함할 내용:

- 화제의 は
- 주어의 が
- 신정보의 が
- 대조의 は
- 의문사 + が
- 종속절 안의 が
- 주절과 종속절에서 は/が가 달라지는 경우

너무 언어학적으로 설명하지 말고

窓が開いている。
= 창문이 열린 상태

窓が開けてある。
= 누군가가 의도적으로 창문을 열어둔 상태

==================================================
10 경어・청해 축약
==================================================

경어는 N2에 필요한 핵심만.

존경어:

いらっしゃる
おっしゃる
なさる
召し上がる
ご覧になる

겸양어:

参る
申す
申し上げる
伺う
拝見する
いただく

그리고

お〜になる
ご〜になる

お〜する
ご〜する

를 포함한다.

핵심 질문은:

"누가 누구를 높이고 있는가?"


청해용 축약형도 포함한다.

ている → てる
てしまう → ちゃう
でしまう → じゃう
ておく → とく
なければ → なきゃ
なくては → なくちゃ
という → って
のだ → んだ

축약형 → 원래 형태 복원 문제를 만든다.
