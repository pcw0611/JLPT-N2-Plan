# N2 컴퓨터 모의시험 검토 — 2026-09-20

대상: `quiz_sites/n2-midterm-mock-exam-20260920.html`

판정: **현재 상태로 공식 문제집 제2집 응시 결과나 N2 접수 판단에 사용하기 부적합.** 아래에는 정답 스포일러가 포함된다. 원본 HTML과 학습 원장은 수정하지 않았다.

## 검증 범위

- HTML 전체 구현 구조 및 내장 107문항 데이터 검사. 문항 번호 107개 모두 고유하며 정답 인덱스 범위 오류 없음. JavaScript 구문 검사 통과.
- 문법·독해·청해의 내용 및 정답을 검토하고 공식 제2집 문법 PDF와 청해 대본 일부 대조. 전 107문항이 공식 원문과 일치하는지 전수 대조한 것은 아님.
- 실제 브라우저 클릭, 시각 배치, 일본어 음성 품질, 155분 연속 실행은 미검증. 브라우저 도구가 로컬 file URL을 보안 정책으로 차단함.
- 사용자의 응시·제출·학습 완료로 기록하지 않음.

## 우선 수정할 결함

### 1. [P1] 공식 원문과 변경·대체 문항이 섞여 있음

HTML 622행 RAW_QUESTIONS, 표지 159행 부근, 결과 내보내기 1822행 이후.

공식 제2집 문법 원문과 비교하면 일부 문제는 일치하지만 문항이 누락·재배치되고 새 문항이 섞여 있다. 예를 들어 공식 問題8의 결혼생활·가방·등산 문항을 현재 파일에서는 찾을 수 없고 프로젝트·인품·논문 조언 문항이 들어 있다. 글의 문법도 같은 화장실 마크 소재지만 지문 후반과 선택지가 바뀌었다. 현재 파일은 공식 문제집을 그대로 디지털화한 시험이 아니다.

청해 76번은 공식 청해 問題1의 **예제**인 결석 시 숙제 확인 대화를 채점 문항으로 사용한다. 공식 대본에서 예제와 본시험 문항을 분리해 다시 매핑해야 한다.

표지의 기관 `公認`, 결과의 `examType: 공식 모의고사`, 개별 해설의 `공식 정답`을 현 상태의 전체 시험에 적용할 근거가 없다. 공식 원문·선택지·번호·정답표를 일치시키거나 수정/자체 제작임을 명확히 표시해야 한다.

### 2. [P1] 문장 배열 정답 오류 — 46·48·49번

세 문제 모두 화면의 별표는 네 칸 중 세 번째지만 저장된 정답이 다르다.

| 문항 | 문맥상 배열 | 세 번째 칸 | 저장 정답 |
| --- | --- | --- | --- |
| 46 | 4 → 2 → 1 → 3 | 1번 `かどうか` | 4번 |
| 48 | 1 → 3 → 4 → 2 | 4번 `その` | 2번 |
| 49 | 2 → 4 → 1 → 3 | 1번 `アドバイスを` | 3번 |

해설도 마지막 칸에 별표를 붙이거나 공식 정답이라는 말로 불일치를 설명하고 있어 함께 고쳐야 한다. 다른 배열의 문법적 가능성도 점검한 뒤 원문 복원이 우선이다.

### 3. [P1] 단일 정답이 성립하지 않는 문항

- 42번: `調べるにしたがって`와 `調べるにつれて` 모두 점진적인 변화 문맥에 사용할 수 있다. 현 문맥만으로 한쪽을 오답 처리하기 어렵다.
- 44번: `努力するしかない`와 `努力するほかない`는 모두 성립한다. `よりない`도 같은 의미로 쓰이는 표현이므로 교체하는 편이 타당하다.
- 103번: 에어컨 교체 제안에 대해 ‘산 지 얼마 안 됐다’, ‘교체에 찬성할 수 없다’, ‘아직 쓸 수 있을 것 같다’가 모두 대화 응답으로 성립한다. 3번만 맞다고 할 상황 단서가 없다.

### 4. [P1] 180점 환산 및 합격권·접수 권고가 부정확함

1642행과 1828행에서 `정답 수 / 전체 문항 수 × 180`을 계산하고 110점 이상이면 합격권 및 N2 접수 강력 추천을 표시한다. JLPT 공식 점수는 단순 정답률 환산이 아닌 척도점수이며 영역별 기준점도 적용된다. 예를 들어 청해를 전부 틀려도 앞 75문항을 맞히면 이 코드에서는 126점 합격권이 된다.

정답 수·정답률과 영역별 성적만 보고하고, 공식 환산점수 및 단정적 합격 판단을 제거해야 한다.

### 5. [P1] 54번이 문법 집계에서 누락됨

54번만 `part`가 일본어 `文法` 대신 한국어 `문법`이다. 1591행 이후 집계와 1806행 이후 내보내기는 `文法`만 센다. 전부 맞히면 화면 문법 통계는 21/21, 내보낸 결과는 21/22가 되어 서로 불일치한다. 문법 해설 필터에서도 제외된다.

### 6. [P1] 청해 임의 건너뛰기와 음성 오류 시 진행

1075행 `nextQuestion()`은 청해에서도 다음 문제로 이동한다. 번호 팔레트만 막아 두었으며 ‘다음’ 버튼은 비활성화하지 않는다. ‘재생 중 임의 이동 차단’이라는 안내와 다르다.

여러 음성 `onerror` 처리에서 오류를 알리고 멈추는 대신 다음 발화·선택지·답변 카운트다운으로 진행한다. 음성이 나오지 않아도 오답·미응답으로 끝날 수 있다. 일본어 음성 준비 확인, 오류 시 중단 및 재개, 이전 문제 콜백의 취소가 필요하다.

### 7. [P1] 청해 78번 질문 대상과 대화 인물 불일치

질문은 여학생이 갈 곳을 묻는다. 대화에서는 화자2가 도서관에 가자고 말하고, 화자1이 증명서를 받으러 사무실에 먼저 간다고 답한다. 저장 정답은 사무실이다. 화자2를 여성으로 사용하는 현재 음높이·설명 관례를 따르면 질문 대상과 정답이 엇갈린다. 성별과 역할을 명시적으로 지정하고 대본·질문을 맞춰야 한다.

## 추가 개선 사항

- 107번 선택지에 화면 마킹 번호 1번과 문장 안의 ‘3번 플랜’ 등이 중복 표시되어 번호 혼동 가능성이 있다.
- 청해는 공식 녹음 파일이 아니라 내장 대본을 브라우저 TTS로 읽는다. 50분은 실제로 보장되지 않으며 2교시 타이머는 경과시간만 표시한다. 공식 문제집 재현 여부와 TTS 연습 모드를 구분해야 한다.
- `分からない`가 없고 미마킹과 모름을 합친다. 프로젝트의 오답·모름·미응답 구분 규격 미충족.
- 시험 전·중 한국어가 다수 노출된다. 106번 선택지에는 `カ누`라는 혼합 표기도 있다.
- 해설 ruby에 일본어 읽기 대신 한국어 뜻을 넣은 예가 있고, 문제 원문 한자의 학습용 후리가나가 완비되지 않았다.
- 복습일이 모든 문제에서 D+1: 2026-09-21로 고정되어 있다. D+3·D+7 및 실제 응시일 기준 계산이 없다.
- 답과 시간은 메모리에만 있어 새로고침 시 복원되지 않는다. 장시간 시험에는 중단 복원이 필요하다.
- 1교시 타이머는 실제 시각 차이가 아닌 호출 횟수를 세므로 백그라운드 탭이나 절전 시 지연될 위험이 있다.
- 외부 Tailwind 스크립트 로딩에 의존하며 자체 CSS에 `.hidden` 대체 정의가 없다. 해당 스크립트 로딩 실패 시 시험·결과 화면 숨김이 깨질 가능성이 있다. 네트워크 실패 상황은 실행 미검증.
- 필기와 청해의 정답률 차이만으로 체력·집중력 저하를 단정하는 결과 문구는 영역 실력 차이를 통제하지 못한다.
- 일부 독해 오답 선택지가 ‘법으로 개성을 금지’, ‘텔레파시’, ‘다른 사무소에 침입해 작품을 훔친다’ 등 지나치게 쉽게 제거된다. 공식 N2 난이도를 재현했다고 볼 근거가 약하다.

## 청해 구현 제안 — 공식 음원과 TTS의 구분

**TTS 사용 자체는 결함이 아니다.** 자체 제작·변형 문제 연습에는 TTS를 유지할 수 있다. 다만 공식 문제집 제2집을 그대로 컴퓨터에서 풀려는 목적이라면, JLPT 공식 홈페이지에서 제공하는 해당 책의 청해 음원을 사용하는 방식이 가능하다. 위의 지적은 TTS라는 기술보다 원문 불일치, 재생 오류 처리, 공식 시험과 동일하다는 표시에 관한 것이다.

아래 내용은 구현 제안이며, 이번 검토에서 음원 연결이나 시험 프로그램 수정은 수행하지 않았다.

### 권장안: 공식 음원 + 화면 답안지

1. **원문 연결부터 복원한다.** 공식 제2집의 청해 문제지·정답표·대본과 음원을 한 세트로 대조한다. 현재 파일의 임의 문항 번호를 그대로 연결하지 않고 `대문항 → 소문항 → 답안 번호` 대응표를 만든다. 안내·예제는 채점에서 제외한다. 하나의 대화를 듣고 두 질문에 답하는 유형은 공통 대화와 두 답안 칸을 함께 구성한다.
2. **기존 HTML에서 녹음 파일을 재생한다.** 브라우저의 기본 오디오 기능으로 공식 페이지의 問題1~5 음원을 순서대로 재생하도록 구현한다. 별도의 유료 TTS 서비스는 필요하지 않다. 공식 페이지의 원격 파일 재생 가능 여부는 실제 브라우저에서 확인한다. 원격 재생이 불안정하면 사용자가 공식 페이지에서 받은 파일을 선택하여 로컬 재생하는 방식도 지원할 수 있다.
3. **녹음의 진행을 기준으로 운영한다.** 공식 음원에 포함된 지시·예제·답변 대기 시간을 보존한다. 지금의 문항별 TTS 안내와 고정 6초/12초 카운트다운을 덧붙이지 않는다. 재생 길이는 실제 파일에서 확인하고, 임의로 잘라 50분에 맞추지 않는다. 사용자가 `開始する`를 누른 뒤 재생하고 자동 재생 차단이나 로딩 실패를 처리한다.
4. **화면과 음성을 맞춘다.** 먼저 대문항별 답안지를 제공하고 해당 음원을 연속 재생하는 형태로 구현할 수 있다. 문항마다 화면을 자동 전환하려면 실제 음원을 듣고 문항 시작·답변 종료 시각을 검증한 타임라인을 별도로 작성한다. 문장 길이나 추정 시간으로 전환하지 않는다. 문제지에 없는 대본·선택지 텍스트는 제출 전에 공개하지 않는다. 음성의 선택지 번호와 답안 번호는 고정해 셔플로 어긋나지 않게 한다.
5. **시험 모드와 복습 모드를 구분한다.** 시험 모드에서는 임의 재생 위치 변경·배속·재청취·방송 건너뛰기를 제한한다. 답안 선택과 음원 이동은 별도로 처리해 답안 조작이 음원을 끊지 않게 한다. 제출 후 복습 모드에서는 대본·해설과 재청취를 제공한다.
6. **음성 장애를 응시자의 오답으로 처리하지 않는다.** 시험 전 소리 확인을 제공하고, 로딩 지연·재생 실패 시 자동 진행을 중단한다. 마지막 재생 위치와 답안을 저장하며, 재개·재청취가 발생하면 결과에 중단 이력을 남긴다. 테스트 응답은 실제 학습 원장에 기록하지 않는다.
7. **출처와 결과를 정확히 표시한다.** 원문 대조를 완료한 경우 ‘공식 문제집 제2집을 사용한 개인 학습용 응시 화면’으로 표시한다. 이 HTML 자체가 기관 공인을 받았다는 `公認` 표기는 사용하지 않는다. 결과에는 자료 출처·음원 종류·정답 수·정답률·시간·중단 여부를 기록하며 공식 척도점수는 계산하지 않는다. 공개 사이트에 음원을 복제·재배포하는 경우에는 공식 안내의 이용 조건을 별도로 확인한다.

### TTS 유지안: 자체 제작·변형 문제 연습

- 현재 대본에 맞춘 TTS를 유지하되, 공식 녹음을 사용한 시험과 구별하여 ‘자체 제작/변형 청해 · TTS’로 표시한다. 출처와 음원 종류는 결과 내보내기에도 보존한다.
- 일본어 음성 사용 가능 여부를 시작 전에 확인하고, 화자별 역할·성별·음색을 일관되게 지정한다. 합성 발음이나 음성 장애는 학습자의 듣기 오류와 구분한다.
- 공식 원문과 다른 문제에 공식 음원을 억지로 연결하지 않는다. TTS 연습 성적을 공식 음원 시험과 같은 조건의 결과로 합산하지 않는다.

### 구현 후 확인할 항목

- 공식 음원·문제지·선택지·정답의 대응 및 예제 제외 여부.
- 시작 클릭, 파일 로딩, 대문항 간 연결, 공통 대화의 복수 질문 처리, 마지막 답변 시간 후 제출.
- 제출 전 대본 비공개, 답안 번호 유지, 시험 중 임의 탐색 제한.
- 음성 오류·네트워크 중단·새로고침 복원과 중단 이력의 결과 반영.
- 제출 후 한국어 해설·대본·재청취, 실제 선택 답과 모름·미응답의 구분.
