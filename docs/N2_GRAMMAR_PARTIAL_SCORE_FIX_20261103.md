# 스피드런 중간 종료의 누적 성적 분모 정정

## 원인·변경

결과 화면은 응답한 문항 기준으로 정답률을 계산했지만 저장 데이터의 `totalQuestions`에는 선택한 전체 분량(예: 200)을 넣었다. 홈페이지가 이를 합산하면서 정답3/응답3이 정답3/전체200으로 누적되었다.

- 퀴즈의 저장·자동 기록·홈페이지 집계 분모를 실제 응답 수로 통일했다. 정답·오답·명시적으로 선택한 모름이 분모에 포함된다.
- 풀지 않은 문항은 `unattemptedCount`, `plannedQuestions`, `details.unattempted_questions`에 보관한다. 성적 분모·오답·모름·채점 문항별 기록에는 넣지 않는다.
- 예: 3개를 모두 맞히고 중간 종료 → `correctCount=3`, `totalQuestions=3`, `accuracy=100`, `plannedQuestions=200`, `unattemptedCount=197`, 채점 응답3개.
- 3번째 문제를 보기만 하고 앞의 2개만 답한 경우에는 분모2로 기록한다.
- 서버 제출 API와 조회 API도 원본 응답을 검토해 예전 화면에서 보내는 중간 종료 데이터를 보정한다. 문형 스피드런 v2의 중간 종료만 대상으로 하며 공식 시험·완주·증거가 일치하지 않는 데이터는 임의 추정하지 않는다.
- 기존 타이머·TTS·요일 선택·완주 흐름은 보존했다.

## 기존 데이터 정정

- Cloudflare 온라인 제출 36번, 2026-11-03: 원본에 정답3개·오답0·모름0·미응답으로 잘못 등록한 미진행197개가 있었다.
- 저장된 원본 행을 백업한 뒤 실제 D1 행의 분모를 200→3, 정답률100%로 정정했다. 응답·미진행 문항 내용과 학습시간·날짜·기록 ID는 보존했다.
- D1 원본 재조회: `total_questions=3`, `correct_count=3`, `accuracy=100`, `unattempted=197`, `scored_attempts=3`. 같은 형태의 미보정 행 0건.
- 다른 기존 온라인 제출 35건은 변경 전·후 전체 필드 비교에서 동일했다.
- 로컬 학습 DB에는 이 중간 종료 기록이 아직 수집되지 않았고, 해당 날짜 동기화 보고서에도 포함되지 않아 기존 로컬 성적·학습시간은 변경하지 않았다.
- 기존 Sites DB에는 온라인 제출 테이블/해당 기록이 없음을 연결 도구로 확인했다. 수정된 프로그램은 두 공개 주소에 배포한다.
- 원본 백업·검토한 SQL·보정 감사 기록은 Git 제외 경로 `jlpt-calendar-site/outputs/partial-grammar-repair-20261103/`에 보관했다. SQL은 원본 길이·내용 앞부분·ID·기존 분모·생성시각을 조건으로 해당 행만 수정했다.

## 변경 파일·검증

- `public/exams/n2-grammar-speedrun.html`, `quiz_sites/` 사본: 제출 분모와 미진행 분리.
- `public/exam-auto-submit.js`: 실제 채점 분모 및 미진행 표시.
- `lib/grammar-result.mjs`, `app/api/submit-exam/route.ts`, `app/api/study-days/route.ts`: 서버 제출·조회·누적 보호.
- `scripts/plan_grammar_result_repair.mjs`: 원본 백업으로부터 검토 가능한 조건부 보정 SQL 작성.
- `scripts/test_grammar_results.mjs`: 3/3·혼합1/3·보기만 한3번째 제외·증거 불변·재실행 멱등성·완주/공식시험 보호 검사 통과.
- 기존 7요일/14,000문항 생성·채점/중단 검사, TTS 검사, 제출 반영 Python 테스트 4개 통과. `pnpm build` 통과.
- 실제 보정 SQL은 인메모리 SQLite에서 먼저 실행해 3/3 및 미진행197개 보존을 확인했다. D1은 첫 요청에서 긴 SQL 제한으로 쓰기가 실행되지 않아 원본 중복을 줄인 조건부 SQL로 수정했고, 이후 실제 원본에서 1개 행 수정 및 재조회로 확인했다.
- 인앱 브라우저 실제 홈페이지에서 11월3일 합계 `3 / 3`, `正答率100%`, 오답/모름/미응답 `0 / 0 / 0` 표시를 확인했다. 검증용 성적을 새로 제출하지 않았다.
