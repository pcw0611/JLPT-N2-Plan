## E 지우개 추가

- E는 지우개 ON/OFF, H는 연필 ON/OFF. 다른 도구가 켜져 있으면 해당 키로 바로 전환. 닿은 획 전체를 지우며, 주변 10px와 드래그 이동 경로를 검사해 빠른 이동 중에도 선을 놓치지 않음. 영역별 기존 저장 키·좌표를 보존.
- 한 번의 드래그를 한 작업으로 취급하며, Ctrl+Z로 그리기 또는 지우기를 취소. 지우기 취소 이력은 현재 페이지 세션에 최대 100작업 보관하고 새로고침하면 초기화. 지운 결과 자체는 기존 필기와 같이 브라우저에 저장.
- 실행 확인: 평행 2획 중 한 획만 지우기(2→1), Ctrl+Z 복구(1→2), 빠른 드래그로 두 획 삭제(2→0), 한 번의 Ctrl+Z로 두 획 복구(0→2), E OFF 확인, 새로고침 후 남은 한 획 복원, 클릭으로 남은 획 지우기 확인, OMR 0/2 유지. 테스트 선 정리 완료, 답안 제출 없음.
