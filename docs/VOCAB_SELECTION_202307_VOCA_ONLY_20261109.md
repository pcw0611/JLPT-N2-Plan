# 2023.07 N2 시험 어휘 × JLPT 한끝 Voca 대조

2026-11-09 로컬 Anki 기준. 비교 범위는 **JLPT 한끝 Voca 및 하위 덱 2,797노트/카드**다. 별도 `JLPT N2` 보완 덱, 독해어휘 덱, N1 맛보기, TOEIC는 제외했다. 처음 확인한 3,495개는 별도 JLPT N2 덱을 포함한 수치였으며 이번 최종 선별에는 사용하지 않았다.

**최종 선별 기준: 한끝 Voca에 해당 단어의 표제어 암기 카드가 없으면 신규 후보에 포함한다. 다른 카드의 예문·설명에 나오는 것은 제외 근거로 사용하지 않는다.** 예문 등장 여부는 참고 정보다.

대상 자료: 11/08 응시한 2023년 7월 N2 자료 101문항의 문제·선택지·지문·청해 대본. 원장 시험 ID `online-sub-37`의 실제 오답 여부를 참고했다. 카드 없음은 모름/미학습/오답 원인이라는 뜻이 아니다. 주석에서 뜻을 제공한 단어는 우선순위를 낮췄다. Anki에 카드를 추가·수정하거나 평가하지 않았고, 학습 완료·시간·복습 큐·DB도 변경하지 않았다. AnkiWeb 동기화는 실행하지 않았다.

## 대조 범위와 한계

- Anki: MCP로 한끝 Voca와 하위 덱 노트 ID 2,797개 및 필드 전체를 읽었다. HTML 스타일·루비 읽기를 정리하고 kanji/kana/Basic Front, 뜻·예문을 비교했다. 별도 덱 노트는 최종 비교에서 제외했다.
- 시험: built-in Intl.Segmenter로 시험 텍스트의 어휘 후보를 탐색한 뒤, 활용형·한자/가나 표기·관용구를 직접 정리한 **152개 어휘·표현**을 상세 대조했다. 형태소 사전 기반 전 단어의 완전 추출/원형 복원을 보장하지 않는다.
- 상세 대조 152개 중 표제어 카드 있음 19개, 표제어 카드 없음 133개다. 카드 없음 133개에는 예문/설명에만 있는 8개와 단어 용례도 미확인인 125개가 모두 포함된다. 이는 검토한 후보 범위의 등록 공백이며 모두 모르는 단어이거나 한 번에 추가해야 하는 카드 수라는 뜻은 아니다. 먼저 33개를 확인하도록 정리했다.
- 최종 후보 제외 기준은 동일 어휘·의미의 표제어 카드 존재 여부다. 예문 등장 여부는 참고 정보로만 보존한다. 기존 우선 25개 중 주요 20개는 Anki 서버 검색으로도 재확인했다. 동음이의어, 단일 한자와 다른 합성어, 가나 부분 문자열의 잘못된 중복을 수동 보정했다.
- 현재 로컬 카드 기준이다. 다른 기기의 미동기화 변경은 반영하지 않는다. 현재 기억 여부와 미학습 카드 여부를 이 목록으로 단정하지 않는다.
- 원문 출처: `database/past_exams/2023_07_exam.json`. 결과 원장: `database/jlpt_learning.db`의 `online-sub-37`. 한국어 뜻은 해당 문맥의 간단한 뜻이며 공식 어휘 급수·출현 빈도 표가 아니다.
