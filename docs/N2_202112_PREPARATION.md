## 최신 상태 — 2026-11-10 다운로드 파일 직접 확인

사용자가 다운로드 완료를 알려 Downloads를 확인했다.
`Đề N2 T12-2021 Mark.pdf`와 `(1).pdf`는 각각 7,708,830바이트이며
SHA-256 비교에서 동일한 파일이다. PDF는 실제 21페이지이고 마지막 페이지
(인쇄 쪽 번호 22)에 언어지식·독해·청해 정답표가 포함되어 있다.
문제 페이지와 마지막 정답표를 이미지로 렌더링해 직접 확인했다.
따라서 앞선 '정답표 PDF가 보이지 않는다'는 폴더 목록 기준 안내는
정답표 내용이 없다는 뜻이 아니며 별도 정답 파일 없이 대조를 시작할 수 있다.

청해 Ver 2.0 MP3는 각각 41,647,586바이트인 동일 파일 2개가 있으며
SHA-256은 `0a8cec1068d880d7bb849956d6654724972db0d4682c9a527a81f16e720989ea`다.
기존 ffmpeg로 파일 전체 디코딩이 정상 종료됐고 길이는 43분22.92초다.
전체 문항의 원문/정답/음원 번호 대응, 청취 내용, 브라우저 응시는 아직 미검증이다.
원본 다운로드 파일은 수정하지 않았다. 아래 내용은 이전 조사 이력이다.

2026-11-10 사용자 요청: 내일 시험 제작 및 보기 중복을 포함한 검수.

## 실제 실행한 검사

```powershell
python -X utf8 scripts/audit_exam_data.py database/past_exams/2021_12.json --report docs/N2_202112_DATA_AUDIT.json
```

종료 코드 1로 기존 파일을 부적합 판정했다. 전체 결과는 인접 JSON에 보존한다.
정규화 후 보기 중복, 반복 문제, 문항 수/ID, 정답 인덱스, 임시 내용,
제출 전 한국어, 페이지 대응, 배열 정답과 별표 위치를 검사한다.
이 검사는 문법적 정답 유일성이나 원음 대응을 인증하지 않는다.

검사기 자체는 정상 입력, 전각/공백 정규화 후 중복 보기, 별표 정답 불일치의
세 가지 인메모리 입력으로 실제 실행해 예상 판정을 확인했다.
기존 `2023_07_exam.json`에도 실행한 결과 Q10의 1·3번 `消失` 중복을 발견했다.
이는 별도 원문 대조가 필요한 기존 결함이며 이번 작업에서 문항·점수를 수정하지 않았다.
