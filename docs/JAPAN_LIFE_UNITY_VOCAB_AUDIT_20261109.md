# 일본 취업·생활 어휘 1차 대조 — Unity/C# 개발자

작성: 2026-11-09. 목표: 2027년 상반기 일본 회사 지원. 관심: 개발 회의·관공서. 간단한 주문·요청은 가능하나 즉석 회화에서 인출 어려움도 있다는 사용자 응답을 기준으로 삼았다.

## 결과를 읽는 방법

- 현재 Anki 읽기 전용 조회: 한끝 Voca 및 모의고사 1·2·3회차, 총 2,969장 / 서로 다른 표제어 2,602개. 다른 N2 문법·별도 어휘 덱과 사용자가 카드 밖에서 아는 단어는 이 수치에 포함하지 않았다.
- 미등록은 모른다는 뜻이 아니다. 단어장 밖에서 이미 아는 단어, 한자어로 바로 추론 가능한 단어, 영어로 아는 기술 용어가 포함될 수 있다. 등록되어 있어도 청취·발화 가능 여부는 확인하지 않았다.
- 후보 목록은 사용자 목표에 맞춰 작성한 제한된 체크리스트다. 일본 생활 전체의 필요 어휘를 전수 조사하거나 총 부족량을 추정한 결과가 아니다. 수치는 복합어를 포함한 어휘 항목 수이며, 문장 표현 수는 별도로 센다.
- 표제어·대체 표기·일부 기본형을 비교했다. 예문에만 등장한다는 이유로 제외하지 않았다. 같은 발음의 다른 단어는 중복으로 처리하지 않았다.
- Unity 기술 용어는 개념 자체를 다시 공부하기보다 일본어로 듣고 설명할 수 있는지 확인한다. 회의 용어인 巻き取り 등은 팀별 사용 차이가 있다. 단어 목록의 의료·행정 설명은 어휘 뜻이며 개별 절차나 의료 조언이 아니다.
- 이번에는 Anki 카드를 추가·수정하지 않았다. 단어장 등록 여부만 대조했으며, 실제 회화·청취·사용자 지식 검사는 하지 않았다.
