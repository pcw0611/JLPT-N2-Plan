# 2026-11-02 월요일 문형 스피드런 예문

- 종류: 자체 제작 문형 선택 연습 200문항. 공식 JLPT 문제 원문을 사용하지 않음.
- 기존 문형 번호·선택형 진행·해석/품사 토글·즉시 해설·소리/콤보·오답 재도전·자동 저장을 유지.
- 새 원고: `scripts/grammar_sentences_monday.tsv`. 생성: `python scripts/build_grammar_monday.py`, 반영: `python scripts/sync_grammar_speedrun_html.py`.
- 기존 기본 예문은 보존. 한국시간 2026-11-02 이후 월요일에 새 은행을 선택하며, 다른 요일은 기존 기본 은행. 다른 여섯 요일의 새 은행을 제작했다는 뜻은 아님.
- 미리보기: `/exams/n2-grammar-speedrun?date=2026-11-02`. 날짜 선택은 페이지 로드 시 고정하고 결과의 `sentence_set_id`, `sentence_set_date`에 보존.

## 내용 검토

200개 일본어 문장·번역·빈칸 복원을 검토. 동사/형용사/명사 접속을 허용 범위 안에서 분산하고 명사＋の, な형용사＋な/である, い형용사＋くて/ければ, 동사 사전형/た/ない/て/의지형/ます어간 등을 사용했다.

대표 변화: 001 議論のあげく, 005 静かなうえに, 014 欠席がち, 024 風邪気味, 065 寒くてたまらない, 085 静かでないことには, 086 広くないことはない, 103 慎重なのに対して, 123 広ければよかった, 143 出席しないわけにはいかない, 160 感謝に堪えません, 195 氷のごとき。

복합 표제의 다른 용법을 출제한 경우 현재 문장에 맞는 핵심 해설을 따로 작성했다. 이전 예문에서 인정한 대체 정답은 자동 상속하지 않고 새 문장에서 성립하는 것만 다시 지정했다. 후리가나는 기존 설치 pykakasi로 생성한 뒤 200개 출력물을 읽고 문맥 오독(足跡, 方, 今日, 人, 市場, 十分=10분, 堪え, 通り, 入ろう 등)을 보정했다.

## 실행 검증

- `node scripts/check_grammar_daily.mjs`: 200개 ID/문형 유지, 전 문장 교체, 빈칸 복원, 번역 강조, 접속어 위치, 루비 원문 일치·한자 커버리지 검사 통과.
- 실제 인라인 날짜 선택기 5가지 사례, 실제 문항 생성기 30,000문항 검사 통과. 각 문항 4개 고유 선택지·정답 포함·인정 대체 정답의 오답 보기 배제.
- 실제 채점/종료 함수를 가상 DOM에서 실행: 200개 전부 정답, 전부 모름, 정답67/모름67/오답66. 결과 일치·자동 저장 한 번·세트 식별자 보존 확인. 저장 대상은 메모리 함수이며 실제 DB 쓰기 없음.
- `python -m unittest discover -s jlpt-calendar-site/scripts -p test_grammar_submission.py`: 기존 제출 반영 테스트 3개 통과.
- `pnpm build`: 통과.
- 인앱 브라우저 로컬 프리뷰: 월요일 표시, 200문항 시작, 새 예문, 품사/해석 토글, 정답 후 새 원문·루비·현재 접속 및 전체 접속 규칙 표시 확인.

## 검증 한계

기존처럼 선택지는 매번 무작위이며, 200×199의 모든 문형 대입에 대한 언어적 유일성을 전수 검증한 것은 아니다. 알려진 동의 문형은 제외하고 새 예문의 인정 대체 표현을 지정했다. 해석 OFF에서도 모든 무작위 보기 조합의 유일성을 보증하지 않는다. 문장 셔플 30,000회는 데이터·실행 검사이며 일본어의 전 용법 검증을 뜻하지 않는다. 실제 사이트에 테스트 성적은 제출하지 않았다. 나머지 요일 새 예문은 아직 미작성.
