# JLPT 시험 제작·검토 기준

이 문서는 이 프로젝트에서 문제를 만들거나 컴퓨터용 시험으로 옮기는 모든 AI와 담당자에게 적용한다. 사용자의 현재 지시가 우선한다. 기존 시험 실행기를 재사용하고, 요청한 범위를 완성한 뒤 근거와 함께 전달한다.

## 1. 처음에 시험의 종류를 확정한다

| 종류 | 제작 기준 | 결과 표시 |
| --- | --- | --- |
| 공식 문제집 원문 응시 | 출처가 확인된 원문·그림·선택지·정답·음원을 대응시킨다 | 공식 문제집을 사용한 개인 학습용 시험 |
| 공식 문제 변형 연습 | 바꾼 지문·선택지·순서를 기록하고 정답을 다시 검토한다 | 변형 문제 |
| 자체 제작 | 유형과 목표 난이도를 정하고 독립적으로 정답을 검토한다 | 자체 제작 문제, TTS 여부 별도 표시 |

공식 책 이름을 제목에 붙였다고 공식 문제가 되지 않는다. 일부를 공식 문제에서 가져왔더라도 자체 제작 문제와 섞인 시험 전체를 공식 시험으로 분류하지 않는다. 실제 JLPT 응시와 공식 문제집 연습도 구별한다.

## 2. 출처와 원문을 먼저 확보한다

- 공식 문제에는 자료명·판/발행연도·URL 또는 로컬 파일·페이지·대문항/소문항 번호를 기록한다. 공식 정답표의 대응 위치도 기록한다.
- 출처 원문을 읽지 않았다면 기억이나 추측으로 복원하지 않는다. 원문이 부족하면 확인된 부분만 진행하고 누락 자료를 구체적으로 알린다.
- 공식 디지털화에서는 지문 축약, 오답 선택지 교체, 예제의 채점 문항 편입, 임의 문항 추가를 하지 않는다. 문항 수는 원문에서 센다.
- 텍스트 추출/OCR 뒤에는 별표·빈칸·밑줄·표·그림·주석·선택지 번호를 원본 페이지와 대조한다. 텍스트만 맞아도 위치가 다르면 다른 문제가 된다.
- 공식 원문 응시에서는 원문과 음원의 번호 대응을 보존한다. 원문 자체에 있는 후리가나 등 시각 정보가 프로젝트 일반 규칙과 충돌하면 차이를 알리고 처리 기준을 확정한다. 몰래 바꾼 뒤 완전 동일하다고 하지 않는다.
- 원문 응시의 문항·선택지 순서는 유지한다. 일반 자체 제작 복습시험은 기존 프로젝트의 유형별 셔플 규칙을 따른다. 청해에서 번호를 음성으로 읽으면 화면·음성·정답을 함께 대응시켜야 한다.

## 3. 정답은 해설과 독립적으로 검토한다

정답 번호를 먼저 정한 뒤 그것을 정당화하는 해설을 쓰지 않는다. 먼저 문제를 풀고, 각 오답이 왜 틀리는지 확인한 뒤 정답표·해설과 대조한다.

- **문장 배열:** 모든 조각을 사용한 완성 문장, 선택지 번호 배열, 별표의 칸 번호를 기록한다. `정답 = 번호 배열[별표 칸 - 1]`로 일치시킨다. 1부터 시작하는 표시 번호와 0부터 시작하는 저장 인덱스를 구별한다. 다른 자연스러운 배열이 가능한지도 검토한다.
- **문법·어휘:** 각 선택지를 실제 문장에 대입한다. 유사 문형 둘이 모두 성립하면 ‘출제 의도’를 이유로 하나를 틀렸다고 하지 않는다. 변형/자체 문제라면 문맥·선택지를 수정한다. 공식 문제라면 먼저 전사 오류를 확인한다.
- **독해:** 정답의 근거 문장과 각 오답의 구체적 모순을 기록한다. 상식만으로 제거할 수 있는 엉뚱한 선택지로 난이도를 낮추지 않는다. 표·조건·할인·날짜는 실제 계산으로 확인한다.
- **청해:** 질문 대상, 화자, 최종 결정, 행동 순서가 일치하는지 확인한다. 즉시응답은 모든 선택지를 실제 대화로 이어 읽는다. 여러 응답이 자연스러우면 문항을 고친다.
- **해설:** 실제 표시된 원문과 선택지를 설명해야 한다. 불일치를 ‘공식 정답이므로’라고 덮지 않는다. 후리가나는 일본어 읽기이며 한국어 뜻을 ruby의 읽기 칸에 넣지 않는다.

## 4. 데이터와 채점을 점검한다

- 문항 ID 중복, 필수 필드 누락, 선택지 개수, 정답 범위, 빈 대본/지문, 시험 화면의 의도하지 않은 한국어를 검사한다.
- 영역·유형은 한정된 공통 식별자로 관리하고 표시 언어와 분리한다. `文法`/`문법` 같은 차이로 집계가 빠지면 안 된다.
- 전체 문항 수와 영역별 합계, 화면 결과와 내보내기 결과가 같아야 한다. 전부 정답·전부 미응답·정답/오답/모름/미응답 혼합 입력을 확인한다.
- `分からない`, 미응답, 선택 후 오답, 시간 초과를 구분한다. 시간 초과는 종료 사유도 보존하여 중복 집계하지 않는다.
- 선택지 셔플 후에도 정답과 실제 선택한 답을 안정적인 식별자로 추적한다. 표시 번호만 저장하지 않는다.
- 정답 수와 정답률을 보고한다. `정답률 × 180`을 공식 점수처럼 표시하거나 그것으로 합격·접수 결정을 단정하지 않는다. 영역별 하한 위험을 총점으로 숨기지 않는다.
- 복습일은 실제 응시일 기준 D+1·D+3·D+7을 계산한다. 기존 학습 원장의 복습 사슬 운영 원칙을 적용하며, 정답과 테스트 데이터에 새 오답 복습을 만들지 않는다.

## 5. 청해 음원을 목적에 맞게 선택한다

- 공식 제2집은 공식 홈페이지에 녹음이 제공된다. 원문 응시에는 해당 녹음과 화면 답안지의 조합을 우선한다. 구체적인 연결 방법은 `docs/N2_MOCK_EXAM_REVIEW_20260920.md`의 ‘청해 구현 제안’을 참고한다.
- 자체 제작·변형 문제에는 TTS를 사용할 수 있다. **TTS 자체를 결함으로 취급하지 않는다.** 음원 종류와 문항 출처는 별도로 표시한다.
- 공식 녹음에 들어 있는 안내·예제·대기 시간을 보존한다. 합성 안내와 고정 답변 시간을 중복 추가하지 않는다.
- 한 대화에 질문이 여러 개라면 공통 대화를 보존한다. 질문 사이에 정답을 알려주거나 대화를 임의로 쪼개지 않는다.
- 사용자가 시작하기 전 소리를 확인할 수 있게 한다. TTS는 일본어 음성과 화자 역할을 확인한다. 음성 준비/재생 실패 시 멈추고 원인을 표시한다. 조용히 다음 문항으로 넘어가지 않는다.
- 시험 모드의 이동·재생 제한을 버튼과 실제 동작 모두에 적용한다. 다음 문제로 이동할 때 이전 음성·예약된 콜백·타이머가 남지 않아야 한다.
- 제출 전에는 해당 유형의 공식 문제지에 없는 대본·질문·선택지를 공개하지 않는다. 제출 후에는 한국어 해설과 재청취를 제공한다.

## 6. 컴퓨터 시험은 실제 응시 흐름으로 확인한다

- 시작 전 타이머 정지, 시작 클릭 후 작동, 선택/해제, 이동 후 답 유지, 시간 종료, 휴식, 청해, 마지막 답변, 제출, 결과 복사를 확인한다.
- 실제 시각 기준으로 제한시간을 계산하고 절전·백그라운드·네트워크 실패를 처리한다. 새로고침 복원과 음성 중단은 상태와 이력을 보존한다.
- 문제 화면은 일본어, 해설은 한국어라는 규칙을 지킨다. 화면 크기 때문에 지문·표·답안이 잘리거나 제출 전 정답이 보이지 않는지 확인한다.
- 시험 종료 후 답을 바꾸거나 중복 제출해 결과가 달라지지 않아야 한다. 테스트는 실제 학습 기록을 쓰지 않는 환경에서 진행한다.
- 외부 스크립트가 실패해도 결과·정답이 시험 전에 노출되지 않도록 화면 숨김을 자체적으로 보장한다.
- 접근 제한이나 도구 연결 문제로 실행하지 못했다면 그 부분을 미검증으로 남긴다. 코드가 있다는 사실이나 구문 검사 통과를 실행 성공으로 보고하지 않는다.

## 7. 전달 전에 근거를 남긴다

매 제작물에 아래 항목을 짧은 검증 기록으로 남긴다. 별도 거대한 보고서를 매번 만들 필요는 없으며 기존 시험 메타데이터나 문서를 재사용한다.

| 항목 | 남길 내용 |
| --- | --- |
| 시험 식별 | 제목, 출처 종류, 문항 수, 음원 종류, 파일/실행 주소 |
| 원문 대조 | 확인한 자료·페이지·문항 범위, 미대조 범위 |
| 정답 검토 | 배열 계산, 복수 정답 검토, 남은 불확실성 |
| 데이터/채점 | 실제 실행한 검사와 결과, 화면/내보내기 일치 여부 |
| 사용 흐름 | 실제 조작한 경로, 브라우저, 음성 재생 확인 범위 |
| 한계 | 미검증 기능, 중단 사유, 알려진 결함 |

정답 오류·복수 정답·출처 오표기·채점 누락·음성 실패 후 자동 채점이 남아 있으면 ‘응시 준비 완료’라고 전달하지 않는다. 검증 범위가 일부라면 ‘전 문항 검증 완료’, ‘실제 시험과 100% 동일’, ‘공인’ 같은 표현을 쓰지 않는다. 검토용 초안은 남은 문제를 명시해 전달할 수 있다.

## 8. 오류를 발견했을 때

해당 문항뿐 아니라 같은 생성 방식으로 만든 문항 전체를 점검한다. 문장 배열 정답 하나가 틀렸다면 모든 배열 문항의 별표 위치를 다시 계산하고, 분류 하나가 틀렸다면 전체 분류 집계를 검사한다. 이미 응시했다면 원래 결과와 정정 결과를 함께 보존하고 사용자에게 차이를 알린다. 사용자 답을 기존 잘못된 정답에 맞추지 않는다.
