- 자체 제작 문형 선택 연습. 공식 JLPT 원문을 복원하거나 인용한 자료가 아님.

- 추가 6요일은 문형마다 접속·어휘 3가지와 의미 있는 후속 문맥 2가지를 작성해 조합. 화/수/목은 첫 후속 문맥, 금/토/일은 두 번째 후속 문맥을 사용한다. 일부 앞부분은 간격을 두고 다시 등장하며 1,200개를 독립된 원고로 썼다는 뜻은 아니다.
- 허용되는 품사 범위 내에서 동사 사전/た/て/ない/의지/가능/ます어간, い·な형용사, 명사 및 조사 접속을 분산. 동사 전용 표현에 명사·형용사를 억지로 연결하지 않음.
- 원고 `scripts/grammar_weekly_matrix.tsv`, 생성 `scripts/build_grammar_weekly.py`, 은행 `scripts/n2_grammar_weekly.json`. 월요일 원고·기존 기본 은행은 별도로 유지.

## 사용

- `/exams/n2-grammar-speedrun`: 한국시간 오늘 요일 자동 선택.
- 시작 화면의 요일 선택기로 날짜와 관계없이 월~일 또는 기존 기본 예문 선택.
- 공유 링크 `?set=monday`부터 `?set=sunday`까지 지원. `?set=auto`, `?set=baseline`도 지원.

- 복습 결과는 예문 요일과 별개로 실제 응시일에 기록하며, 결과 메타데이터에 은행 ID·요일 선택·실제 날짜를 보존.
- 기존 코스·문항 수·해석/품사·소리/콤보·즉시 해설·오답 재도전·자동 저장 유지.
- 실행면 변경: `jlpt-calendar-site/public/exams/n2-grammar-speedrun.html` 및 `quiz_sites/` 사본. 선택기 원본 `scripts/grammar_weekly_selector.js`, 자동 저장 표시 `jlpt-calendar-site/public/exam-auto-submit.js`. 기존 학습 원장·로그·일정에는 쓰지 않았다.

## 일시중지·중간 종료

- `一時停止` 시 문제를 가리고 배경을 inert 처리, 퀴즈 단축키·선택·이동을 차단한다.
- `再開する` 시 같은 문항·선택/해설 상태로 복귀. 전체 타이머와 문항별 응답 시간에서 일시중지 시간을 모두 제외한다.
- `ここまでで終了`는 시간을 멈추고 응답/미응답 수를 보여 준다. 취소하면 이전 상태로 복귀하며, 원래 일시중지 중이었다면 계속 정지 상태를 유지한다.
- 중간 종료는 화면·저장·홈페이지 누적 모두 응답한 문항 기준. `totalQuestions`와 `answeredQuestions`는 실제 응답 수이며 정답+오답+모름의 합계다. 원래 선택한 분량은 `plannedQuestions`, 풀지 않은 분량은 `unattemptedCount`로 보관하며 성적 분모에서 제외한다. (2026-11-03 저장 분모 오류 정정)
- `details.scoring_version=answered-v1`, `accuracy_denominator=answered_items`, `termination_reason=early`, `planned_items`, `answered_items`, `unattempted_items`와 일시중지 시간·횟수를 보존한다. `attempts`는 푼 문항만, `unattempted_questions`는 미진행 문항 보관용이며 채점·오답 복습 대상에서 제외한다.
- 한 문항도 응답하지 않은 종료는 결과 화면만 보이고 학습 성적을 제출하지 않는다. 중복 종료 시 자동 저장도 중복 호출하지 않는다.
- 자동 저장 토스트도 응답 문항 분모와 미응답 수를 구분한다. 다른 퀴즈는 기존 분모를 유지한다.

## 한계

원고의 접속·문맥 조합을 검토하고 알려진 대체 정답을 은행별로 지정했으나, 기존 무작위 오답 보기의 모든 문형 대입을 언어적으로 전수 검증한 것은 아니다. 생성 반복 검사는 실행·구조 검사이며 모든 보기 조합의 정답 유일성을 보증하지 않는다. 루비는 기존 pykakasi와 문맥별 보정(十分=10분/충분, 方, 床, 偉ぶる, 二か月, 通っていた 등)을 사용하며 외부 일본어 교사의 감수는 받지 않았다. 정식 모의고사 성적으로 취급하지 않는다.
